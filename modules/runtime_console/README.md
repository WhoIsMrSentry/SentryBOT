# Runtime Console

SentryBOT icin logosuz, panel tabanli terminal gorunumu.

- Dashboard ve compact modlari
- Kamera/VLM saglik sorgularini konsolda gizleme
- Tekrarlanan arka plan isteklerini ozetleme
- Tam teknik loglari `logs/sentry.log` dosyasinda koruma
- Renk ve Unicode desteklenmezse sade ASCII fallback

Yapilandirma: `modules/runtime_console/config/config.yml` ve `modules/logwrapper/config/config.yml`.
