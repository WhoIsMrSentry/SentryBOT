# System Control Module

Consolidated module that provides state management, diagnostics, telemetry, configuration center, and notifier services.

## Submodules
- \state_manager\: Central state store for robot variables.
- \diagnostics\: Hardware and software health checks.
- \	elemetry\: Periodic status reporting.
- \config_center\: Runtime configuration overrides.
- \
otifier\: Telegram bot and external notifications.
