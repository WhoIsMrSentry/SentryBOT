# Create PR

## Branch Formatı
- `feat/<modül>-<açıklama>` — Yeni özellik
- `fix/<modül>-<açıklama>` — Hata düzeltme
- `refactor/<modül>-<açıklama>` — Refactor

## PR Şablonu
`.github/pull_request_template.md` kontrol listesini doldur.

## Tam Prosedür
`.sentrybot/skills/create-pr.md` dosyasını oku.
